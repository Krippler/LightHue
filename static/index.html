Console Settings

Bridge send rate

Global ceiling on commands sent to the bridge, across every flickering light. Philips advises against sustained bursts past ~10/sec.

When flicker stops

The console reads each bulb’s colour and brightness before it starts flickering, and restores it on stop — including after a container restart that interrupted a run.

Console password

Custom Lightstyles

One letter per frame, a darkest through z brightest — the same encoding Quake used, and every built-in pattern here is written in it. The speed is saved with the pattern, so picking it later brings its timing along. Saved patterns show up in every light’s pattern list.

Share patterns

Export yours to a small JSON file you can send to someone, or load a file they sent you. Anything you already have is left alone.
